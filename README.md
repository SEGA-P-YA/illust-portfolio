# イラストポートフォリオ（本番サイト）

家族のイラストポートフォリオサイトの本番リポジトリです。

## 構成

- サイト生成: Jekyll（GitHub Pages の標準ビルド）
- 作品管理: Pages CMS（https://app.pagescms.org でこのリポジトリを開く）
- 作品データ: `_works/` に 1作品＝1つの Markdown ファイル
- 公開: GitHub Pages（main ブランチ / ルート）

## 作品の追加・編集（Pages CMS）

1. Pages CMS にログインし、このリポジトリの「作品」を開く
2. 作品を追加・編集する
   - **slug**: 詳細ページのURLになる英数字ID（例: `summer-sky-2026`）。半角英数字とハイフンのみ。ファイル名にも使われる
   - **作品画像**: 原画のままアップロードしてOK（下記の自動最適化が働く）
   - **サムネイル画像**: 通常は空でOK（自動生成される）
   - **詳細ページを作る** をONにした作品だけ、モーダルに「詳細を見る」が出て、`/works/<slug>/` の詳細ページが作られる
   - **メインビジュアルに設定する** をONにした作品がトップのスライドショーに出る
   - **公開する** をOFFにした作品はサイトに表示されない

## 画像の自動最適化

- Pages CMS からアップロードされた原画は `assets/originals/` に保存される（原画は変更・削除されない）
- GitHub Actions（`.github/workflows/optimize-images.yml`）が自動で動き、`assets/images/` に掲載用 WebP を生成する
  - メイン画像: 長辺 2048px 以内・WebP 品質 82（ファイル名: `<元ファイル名>-2048.webp`）
  - サムネイル: 長辺 800px 以内（ファイル名: `<元ファイル名>-800.webp`）
- 処理済みかどうかは原画のハッシュ（`assets/images/manifest.json`）で判定するため、同じ画像が再圧縮されて劣化することはない
- 処理結果は Actions の実行サマリーで確認できる。失敗した場合は Actions のログに理由が残る
- SVG / GIF は変換されず、そのまま表示される
- 原画はこのリポジトリとは別に、手元（PCやクラウドストレージ）にも必ず保管すること

## プロフィール・SNSリンク

当面はサイト側で固定管理。変更する場合は `_config.yml` の `profile:` を編集する（SEGA担当）。

## GA4・お問い合わせフォーム

- GA4: 測定IDを取得したら `_config.yml` の `ga4_id` に設定する。計測イベント（作品モーダル表示・詳細ページ閲覧・カテゴリー選択・メインビジュアル表示・お問い合わせ閲覧/送信）は実装済みで、個人情報は送信しない
- お問い合わせフォーム: フォームサービス（Formspree等）のエンドポイントを取得したら `_config.yml` の `contact_form_endpoint` に設定する。ハニーポットによるスパム対策は実装済み。未設定の間はフォームの代わりにXのDMへの案内が表示される
